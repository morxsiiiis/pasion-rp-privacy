Privacy Policy

Esta Política de Privacidad explica cómo Pasion RP utiliza la información necesaria para proporcionar sus servicios dentro de Discord.

Información que utilizamos

El bot puede utilizar información básica proporcionada por Discord necesaria para funcionar dentro del servidor, como:

  • ID de usuario de Discord
  • Nombre de usuario
  • ID del servidor
  • Roles necesarios para la verificación

Uso de la información

La información se utiliza únicamente para proporcionar las funciones del bot, incluyendo el sistema de verificación y la administración de roles dentro de Pasion RP.

Almacenamiento de información

Pasion RP no vende ni comparte información personal de los usuarios con terceros. La información solamente se utiliza cuando es necesaria para proporcionar las funciones del bot.

Servicios de terceros

El bot utiliza Discord para proporcionar sus funciones. El uso de Discord está sujeto a las políticas y términos de Discord.

Contacto

Si tienes preguntas relacionadas con esta política, puedes contactar al equipo administrativo de Pasion RP mediante el servidor oficial de Discord.
